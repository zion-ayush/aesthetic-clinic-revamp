# The Aesthetic Clinic - Homepage Redesign & Revamp

A modern, high-performance redesign for a luxury plastic & cosmetic surgery clinic. Built to showcase interactive UI components, modern layout patterns, and clean code structure.

## Features
- **Interactive Before/After Slider:** Custom vanilla JS comparison tool.
- **Smart Treatment Selector:** Filterable procedure guide and cost estimator.
- **Glassmorphism UI:** Dark obsidian theme with gold accents and smooth micro-interactions.
- **Responsive & Accessible:** Fully optimized across mobile, tablet, and desktop viewports.

## Tech Stack
- HTML5, CSS3 (Variables, Grid, Flexbox)
- Vanilla JavaScript (ES6+ Modules)
